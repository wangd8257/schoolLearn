# 幼小衔接工作台设计说明

## 目标

交付一个免费、无后端、可部署到 GitHub Pages 的静态 PWA。首次在 iPad Safari 打开后可添加到主屏幕；核心功能离线可用，所有数据仅保存在当前设备。

## 信息架构

- 首页：试卷、阅读、游戏、配置模板四个入口与最近记录。
- 试卷目录：未作答、作答中、待批改、已批改，按时间倒序；支持复制、重命名、二次确认删除。
- 试卷生成：选择学科模板、题量、A4 横竖版和具体参数；保存并复用配置模板。
- 阅读资料：古诗、成语故事、汉字学习、拼音、绘本、英语阅读及自定义分类。
- 游戏：9×9 汉字组词消消乐、英语实物与单词拖拽配对。

## 数据模型

- IndexedDB 保存配置模板、试卷快照、黑笔笔画、红笔笔画、阅读资料、绘本页面和游戏记录。
- 已生成试卷是独立快照，不随模板修改变化。
- 试卷状态：未作答 → 作答中 → 待批改 → 已批改。
- 黑笔和红笔为独立矢量笔迹层；橡皮擦只处理当前颜色层。

## 试卷与数学模板

模板覆盖横式、缺项、竖式、比较大小、列式计算、连加、连减、连续加减、凑十法、破十法、进位、退位、乘法、除法、人民币以及时间/长度/质量/面积/容量单位换算。

- N 以内：所有参与数字、每步中间结果和最终结果均处于 0～N。
- 减法无负数。
- 混合加减数字个数 3～10，默认 3。
- 普通横式和缺项题每题只有一个空格；过程题允许多个过程框。
- 有余数除法满足 0 ≤ 余数 < 除数。
- 应用题 1～3 步，默认 1 步，按步骤显示列式框和最终作答框。

## 手写与打印

- 只有 Apple Pencil/pen 指针能产生笔迹；手指负责滚动、点读和控件操作。
- Pencil 可操作全部控件和游戏。
- A4 横向或纵向；可打印空白、黑笔作答、红笔批改最终版。

## 阅读

- 家长输入或粘贴内容；纯文字资料支持覆盖描红、描红行加仿写行。
- 中文逐字、英文逐词跟随系统朗读高亮；边界事件不可用时按语速估算。
- 支持单段朗读和全文连续朗读并自动滚动。
- 绘本支持多图、多文本框、拖动定位、排序和上传，不提供描红。
- 内置 15 本中文、5 本英文原创短绘本。

## 游戏

- 汉字消消乐：9×9，路径只允许上下左右相邻、可转弯且格子不可重复；词长 2～4 可配置；消除后留空；无可消除项时重排；棋盘始终可完全消除；自定义词库不足时由内置词库补齐。
- 英语配对：每关 2～20 项，默认 10；拖动插画到英文单词区域，错误返回原位并累计错误次数；内置 300 个三年级常用词条。
- 两款游戏记录开始时间、完成时间、用时和错误次数。

## 视觉与响应式

- iPad 采用左侧纵向导航；手机折叠为顶部抽屉。
- 风格为明亮纸艺学习乐园，减少过度动画，操作按钮满足触控尺寸。
- 打印样式移除导航和控件，保持题目与书写区分页完整。

## 非目标

- 不提供账号、云同步、AI 在线生成、自动判题、手写识别、发音评分、视频和运动模块。
- Safari 网站数据被清理后，本地记录可能丢失，用户已接受。
