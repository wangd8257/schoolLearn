# 幼小衔接工作台实施计划

## 完成标准

1. 静态 PWA 可启动、安装和离线访问。
2. 所有已确认模块可操作并持久化。
3. 数学生成器对范围和过程约束有自动测试。
4. 黑笔、红笔和原始试卷三层隔离。
5. 两款游戏可完成一局并保存记录。
6. A4 横竖版与三种打印视图可用。
7. iPad 横竖屏和手机宽度下无阻塞性布局问题。

## 工作包

- WP1：应用壳、路由、存储、PWA、响应式视觉。
- WP2：数学模板配置、题目生成和生成器测试。
- WP3：试卷快照、状态流转、Pencil 双笔迹层、打印。
- WP4：阅读资料、朗读高亮、描红、绘本编辑器和内置绘本。
- WP5：汉字消消乐、英语配对、词库与游戏记录。
- WP6：端到端集成、兼容性检查、部署与最终审计。
