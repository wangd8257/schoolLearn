# SillyTavern 本地安装设计

## 目标

在 `D:\\git-programs\\SillyTavern` 安装官方 SillyTavern 项目，完成依赖安装、启动与本地访问验证。

## 范围

- 使用 Git 克隆官方仓库。
- 安装项目声明的 Node.js 依赖。
- 仅启动本地服务并确认页面可访问。
- 保持默认配置；不配置模型 API、代理、账户或公网访问。

## 执行方式

1. 确认目标目录不存在同名项目，避免覆盖现有内容。
2. 克隆官方仓库至目标目录。
3. 按仓库提供的锁文件或脚本安装依赖。
4. 启动服务，读取实际监听地址与错误输出。
5. 请求本地地址，确认服务返回成功响应后停止临时验证进程或保留运行状态（按启动方式决定）。

## 验收标准

- 项目文件位于 `D:\\git-programs\\SillyTavern`。
- 依赖安装命令成功结束。
- 服务可启动且无阻断错误。
- 本地访问地址可返回页面响应。

## 风险与处理

- 本机 Node.js 24.18.0 可能与项目要求不兼容。仅在实际报错证明不兼容时，报告所需版本；不自动更换 Node.js。
- 若目标目录已存在，停止并请求用户决定是否复用或另选路径。
